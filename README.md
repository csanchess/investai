# GPT-2 ESG & Financial Assistant (Streamlit Cloud)

This Streamlit app allows you to:
- Fetch financial and ESG data from Yahoo Finance
- Build a text corpus for fine-tuning GPT-2
- Fine-tune GPT-2 on your custom dataset
- Ask questions and generate AI insights

## Deployment on Streamlit Cloud

1. Push this repository to GitHub.
2. Go to [Streamlit Cloud](https://streamlit.io/cloud) → “New App” → select your GitHub repo.
3. Set Python version: 3.7–3.10
4. Streamlit Cloud automatically installs dependencies from `requirements.txt`.
5. Run the app:
   - Enter tickers in the sidebar
   - Build dataset
   - (Optional) Fine-tune GPT-2
   - Ask questions in the main area
